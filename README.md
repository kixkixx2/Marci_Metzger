# Marci Metzger | The Ridge Realty Group

> Luxury real estate editorial web publication for Marci Metzger, licensed REALTOR® and broker associate with The Ridge Realty Group in Pahrump, Nevada.

---

## Overview

A high-end editorial digital experience designed with understated sophistication, inspired by architectural monographs and luxury desert living in Southern Nevada. Built around verified business credentials, authentic client track records, and original high-resolution photography.

### Key Sections
1. **Sticky Restrained Navigation:** Fluid height reduction on scroll, direct click-to-call, and mobile slide-out drawer.
2. **Cinematic Hero:** Mountain Falls golf waterways and Spring Mountains panorama with live office status indicator.
3. **Editorial About:** Marci Metzger's nearly 30-year industry journey (Seattle broker to Southern Nevada) and verified 2021 sales performance ($28.5M closed volume).
4. **Sell ("Get It Sold"):** Strategic seller representation, staging reach, and valuation consultation.
5. **Buy ("Find Your Place"):** Local Mountain Falls lifestyle insight, contractor network, and relocation guidance.
6. **Property Search:** Luxury filter interface (location, property type, beds, baths, price range) with isolated MLS gateway architecture.
7. **Featured Residences:** Asymmetric editorial showcase with interactive property detail modals.
8. **Capabilities & Advisory:** 5 structured service pillars (commercial, residential, buyer concierge, seller marketing, and financing).
9. **Visual Portfolio:** Asymmetric magazine photo mosaic with category filters and fullscreen lightbox viewer.
10. **Final Closing CTA:** Streamlined consultation trigger.
11. **Direct Contact & Office:** Verified physical office address (3190 HW-160, Suite F), daily hours schedule (8:00 AM – 7:00 PM), interactive directions link, and validated inquiry form.
12. **Editorial Footer:** Official industry affiliations (REALTOR®, Equal Housing Opportunity, Pahrump Valley Chamber of Commerce) and social profiles.

## Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/your-username/your-repo-name.git

# Navigate to project directory
cd your-repo-name

# Install dependencies
npm install
```

### 3. Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Production Build
```bash
npm run build
